## 🔥 Neden HaxScipt Client?

Bu proje, standart tarayıcıların hantallığından kurtulup, **Real Soccer** sunucularında rekabetçi avantaj sağlamak isteyen oyuncular için sıfırdan tasarlandı.

### ⚡ Performans & Optimizasyon (YENİ)
> **"Türkiye'de Bir İlk"**
* **🛠 Gömülü Chrome Flags Yöneticisi:** Tarayıcı derinliklerindeki ayarları (flags) client arayüzüne taşıdık. Kendi donanımına göre input lag'ı en dibe çekebilirsin.
* **🚀 Optimize Chromium Yapısı:** Gereksiz tüm servisler kapatıldı. Minimum RAM kullanımı, maksimum işlemci odaklanması.
* **📏 İnce Çizgi Modu (Thin Line):** Belki de dünyada tek! **`J`** tuşuna basarak veya ayarlardan açarak oyun içi çizgileri inceltebilirsin. Bu sayede hem FPS artar hem de top kontrolü keskinleşir.

### 🧿 Temel Özellikler
* **🟢 HaxScipt Hızlı Erişim:** Sunucu IP'si aramaya son. Panelden tek tıkla HaxScipt sunucularına en hızlı yoldan bağlan.
* **🔗 Gelişmiş Discord RPC:** Oyundaki durumun (Skor, Oda Bilgisi) Discord profilinde anlık görünür.
* **🛡️ Güvenlik Kalkanı:** Geliştirilmiş hile ve zararlı eklenti engelleme sistemi ile adil oyun.
* **🎨 Kişiselleştirme:** Karanlık mod, özel temalar ve profil adlandırma sistemi.

## ❓ Sık Sorulan Sorular (SSS)

| Soru | Cevap |
| :--- | :--- |
| **İnce Çizgi (Thin Line) nasıl açılır?** | Oyun içindeyken **`J`** tuşuna basmanız veya Ayarlar menüsünden aktif etmeniz yeterlidir. |
| **FPS'im artar mı?** | Evet. Chrome Flags ayarları ve gereksiz servislerin kapatılmasıyla standart tarayıcılara göre ciddi FPS artışı sağlanır. |
| **Client güvenli mi?** | Tamamen güvenlidir. Kodlar açıktır ve GitHub üzerinden checksum doğrulaması yapabilirsiniz. |
| **Oda paneli çalışmıyor?** | Oda listesi sayfasına giriş yaptığınızda veriler otomatik olarak çekilecektir. |
